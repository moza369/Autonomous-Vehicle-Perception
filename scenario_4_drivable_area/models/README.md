# Models

This directory stores the trained model used by Scenario 4.

The model is **not included** in this repository because it exceeds GitHub's recommended file size.

## Required Model

File name:

```text
yolov8n-seg.onnx
```

Place the model inside this folder:

```text
models/
└── yolov8n-seg.onnx
```

## Download

Download the model from one of the following:

- Google Drive:
  https://drive.google.com/drive/folders/1LkSNqhx-AFARF89v4HnmBwZzwsu2dqty?usp=drive_link


After downloading, the folder should look like:

```text
models/
├── README.md
├── .gitkeep
└── yolov8n-seg.onnx
```

Model size: approximately 108 MB.

It is distributed separately because GitHub repositories should avoid committing large binary files.
